## 📌 Sobre o Projeto
Aplicação *backend* de sistema bancário desenvolvida em Python aplicando conceitos avançados de **Programação Orientada a Objetos (POO)**, validações de regra de negócio, tratamento de exceções customizadas e modularização do código.

> 📌 **Nota de Autoria:** Projeto prático guiado, desenvolvido durante a formação na **Data Science Academy (DSA)**, mantendo a estrutura original de módulos do curso para fins educacionais e aprimorado para composição de portfólio.

## 🎯 Objetivo do Projeto
Desenvolver uma solução backend robusta e escalável capaz de gerenciar operações bancárias fundamentais (abertura de contas, depósitos, saques, transferências e emissão de extratos), garantindo a integridade dos dados e a separação clara de responsabilidades.

---

## 🚀 Funcionalidades Principais
- **Abertura e Gestão de Contas:** Cadastro e controle estruturado de clientes e dados bancários.
- **Operações Financeiras:** Fluxos de depósitos, saques, transferências e verificação de saldos.
- **Extrato Transacional:** Emissão detalhada e organizada do histórico de movimentações.
- **Tratamento de Exceções:** Algoritmos de validação contra saldo insuficiente, valores inválidos e entradas incorretas.

---

## 🛠️ Tecnologias e Conceitos Aplicados
- **Linguagem:** Python 3
- **Conceitos:** Programação Orientada a Objetos (POO), Estruturas de Dados, Lógica Defensiva e Modularização.

---

## 📊 Aplicação no Contexto de Ciência de Dados
Apesar de ser uma aplicação *backend*, os fundamentos aplicados conectam-se diretamente à Engenharia e Ciência de Dados:
1. **Garantia de Data Quality:** A validação rigorosa de entradas impede a gravação de dados corrompidos.
2. **Rastreabilidade e Trilha de Auditoria:** O registro histórico de transações simula a geração de logs de consumo utilizados em análises de detecção de fraudes.
